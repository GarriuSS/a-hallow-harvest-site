Support

Found a bug or need help? Write to sansal.akdgn1903@gmail.com. Please include your iPhone model and, if you can, a screenshot.

Common questions

I bought the full game but it's locked again. Open Settings in the game and tap "Restore Purchases", signed in with the same Apple ID you bought it with.

Will I lose my progress if I buy the full game? No. Your save carries on where you left it.

Does the game need the internet? No. It plays fully offline. The App Store is only needed for the purchase itself.
